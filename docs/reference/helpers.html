Read and save array files, resolve project paths, and support configured calls.

load_hdf5_arrays reads named arrays from JAXCMR’s HDF5 layout; load_data uses it to load recall datasets and optionally limit participants. save_dict_to_hdf5 writes arrays in the same layout. Use the generic reader for observations that do not have the fields of a recall dataset.

find_project_root searches for an enclosing project and fails when none is found. resolve_project_root instead chooses a working directory, using an explicit path, Colab’s current directory, or Git discovery with a current-directory fallback. resolve_project_path resolves filenames against an explicit directory. All three return pathlib.Path objects.

import_from_string resolves dotted Python names for configured calls, and format_floats formats numeric labels. Figure saving lives in jaxcmr.plotting; dataset operations live in jaxcmr.dataset.

Project paths

find_project_root Find the nearest enclosing directory containing a marker.
resolve_project_path Resolve a filename against an explicit base directory.
resolve_project_root Choose the working project directory, with a current-directory fallback.

HDF5 arrays and recall datasets

load_hdf5_arrays Read named arrays from the transposed /data HDF5 layout.
load_data Load a recall dataset, optionally keeping the lowest participant IDs.
save_dict_to_hdf5 Write named arrays in the transposed /data HDF5 layout.

Imports and formatting

import_from_string Import an attribute named by a dotted module path.
format_floats Format numeric values with a common number of decimal places.

API entries

find_project_root

jaxcmr.helpers.find_project_root(marker='.git')

Find the nearest enclosing directory containing a marker.

Parameters

Name Type Description Default
marker str File or directory name to seek, starting in the current directory. Defaults to .git; a Git worktree’s marker file also qualifies. '.git'

Returns

Name Type Description
pathlib.Path Absolute path to the first matching directory.

Raises

Name Type Description
FileNotFoundError No matching directory exists between the current directory and its root.

resolve_project_path

jaxcmr.helpers.resolve_project_path(path, base_dir)

Resolve a filename against an explicit base directory.

Parameters

Name Type Description Default
path str or pathlib.Path Native filesystem path. Relative paths are joined to base_dir; absolute paths retain their own root. A leading tilde is expanded. required
base_dir str or pathlib.Path Base for relative paths. A relative base is itself interpreted against the current directory. required

Returns

Name Type Description
pathlib.Path Absolute resolved path, with parent references and symlinks resolved. The destination need not exist; no file or directory is created.

resolve_project_root

jaxcmr.helpers.resolve_project_root(project_root=None)

Choose the working project directory, with a current-directory fallback.

Parameters

Name Type Description Default
project_root (str, pathlib.Path or None) Explicit directory, resolved against the current directory. When omitted, Colab uses the current directory; elsewhere the nearest enclosing Git project is used, falling back to the current directory if none is found. None

Returns

Name Type Description
pathlib.Path Absolute project directory. The function does not print, change the working directory, create directories, or fetch inputs.

load_hdf5_arrays

jaxcmr.helpers.load_hdf5_arrays(path)

Read named arrays from the transposed /data HDF5 layout.

Parameters

Name Type Description Default
path str or pathlib.Path HDF5 file whose /data group contains array datasets. required

Returns

Name Type Description
dict[str, Array] Each stored array is transposed with .T and converted to a JAX array. For matrices, this restores trial rows. No recall fields are required, and no participant selection is performed. JAX’s configured precision determines whether 64-bit values retain their storage dtype.

Raises

Name Type Description
KeyError The /data group is absent.
TypeError The /data object is not an HDF5 group.

load_data

jaxcmr.helpers.load_data(data_path, max_subjects=0)

Load a recall dataset, optionally keeping the lowest participant IDs.

Parameters

Name Type Description Default
data_path str or pathlib.Path HDF5 file in the layout read by load_hdf5_arrays. It must supply subject, listLength, pres_itemnos and recalls with the shapes and dtypes described by RecallDataset. Additional array fields are retained. required
max_subjects int Nonnegative participant limit, ordered by ID. Zero keeps everyone. 0

Returns

Name Type Description
RecallDataset Recall data with stored arrays transposed into trial rows and converted to JAX arrays. Participant selection applies to every field.

Raises

Name Type Description
KeyError The /data group or a required recall field is absent.
TypeError The /data object is not an HDF5 group.

save_dict_to_hdf5

jaxcmr.helpers.save_dict_to_hdf5(data, path)

Write named arrays in the transposed /data HDF5 layout.

Parameters

Name Type Description Default
data mapping of str to NumPy or JAX arrays Arrays stored under their supplied names. Each array is transposed with .T before writing; load_hdf5_arrays reverses that transformation. Recall-specific fields are not required. required
path str or pathlib.Path Destination file. An existing file is overwritten, including its other groups. The parent directory must already exist. required

Returns

Name Type Description
None The file is written and closed; input arrays remain unchanged.

import_from_string

jaxcmr.helpers.import_from_string(import_string)

Import an attribute named by a dotted module path.

Parameters

Name Type Description Default
import_string str Module path followed by one attribute name, such as module.function. The module is imported normally, including any module initialization. required

Returns

Name Type Description
Any The named Python object. Its interface depends on the requested object; the caller determines whether it is suitable for the intended operation.

Raises

Name Type Description
ValueError The path has no module/attribute separator.
ImportError The module cannot be imported.
AttributeError The module does not contain the named attribute.

format_floats

jaxcmr.helpers.format_floats(iterable, precision=2)

Format numeric values with a common number of decimal places.

Parameters

Name Type Description Default
iterable iterable of float Values to format, in label order. required
precision int Number of digits after the decimal point. Defaults to two. 2

Returns

Name Type Description
list of str Fixed-point labels in input order, using Python’s numeric formatting.
