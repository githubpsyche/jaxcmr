jaxcmr.summarize

Summarize fitted parameters and compare models using their scores.

Use the numerical functions, such as aic_scores, when you have arrays of scores and want to work with the results directly. When you have named model records, the comparison functions align rows by participant ID and produce labelled tables. Which observations were fitted and what a score measures must agree across the models in a comparison.

summarize_parameters describes the distribution of parameter estimates across fitted rows. For comparing models, information criteria start with summed negative log likelihoods and penalize the number of free parameters. Paired differences and win fractions describe how the models compare for the same participants. Held-out comparisons use the supplied test scores. For declared nested models, floor_nested_fitness makes a reporting adjustment and records which scores it changed.

To estimate model frequencies in a population, random_effects_model_selection takes one row of log evidences per participant, with one column per model. bayesian_model_selection prepares that comparison from fitted likelihoods using an information-criterion approximation. A single fit to pooled observations supplies only one estimate, regardless of the number of participants who contributed trials.

Input records

ObjectiveSummary Named objectives aligned to a top-level integer subject vector.
ParameterSummary Objective values and parameter columns for a descriptive table.
ModelComparison Named NLL scores, integer row IDs, and free-parameter names.
CVComparison Held-out objectives aligned to a top-level integer subject vector.

ModelComparison

jaxcmr.summarize.ModelComparison: TypedDict

Named NLL scores, integer row IDs, and free-parameter names.

Supply a top-level subject vector aligned with fitness; use [-1] for a single pooled fit. Participant comparisons require the same unique participant IDs across models and exclude pooled fits. Scores must be finite, names distinct, and free must list distinct names rather than bounds. These are caller preconditions, not runtime validation.

aic_scores

jaxcmr.summarize.aic_scores(negative_log_likelihoods, parameter_counts)

Calculate elementwise AIC, 2 * NLL + 2 * k.

Parameters

Name Type Description Default
negative_log_likelihoods array_like Summed negative log likelihood for each fitted parameter set. MSE and mean or scaled NLL are outside this interface. required
parameter_counts array_like Nonnegative integer free-parameter counts, broadcastable to the NLLs. required

Returns

Name Type Description
np.ndarray Scores in broadcast input order, without sorting or aggregation. Scalar inputs produce a zero-dimensional array.

Notes

For NLLs shaped (models, participants), use parameter counts shaped (models, 1). Each fitted row incurs its own penalty. Inputs are unchanged.

Examples

>>> aic_scores([33.0, 30.0], [2, 1])
array([70., 62.])

calculate_aic

jaxcmr.summarize.calculate_aic(results)

Return summed AIC scores, lowest first.

Parameters

Name Type Description Default
results Sequence[ModelComparison] Named records with top-level integer subject IDs, distinct free parameter names and a one-dimensional fitness array. Each fitness value is summed NLL for one independently fitted parameter set. required

Returns

Name Type Description
pd.DataFrame Model and AIC columns, sorted by increasing AIC. Each model’s score is sum_rows(2*NLL + 2*k).

Notes

A pooled fit uses subject=[-1] and incurs one parameter penalty. Participant fits require the same unique IDs across models and incur one penalty per fitted row. Names must be distinct and scores finite.

MSE and mean or scaled NLL cannot substitute for summed NLL. The objective and its sign cannot be inferred from numerical values. These conventions also apply to AICc, BIC and information-criterion weights.

pairwise_median_aic_differences

jaxcmr.summarize.pairwise_median_aic_differences(results, confidence=0.95, n_bootstrap=10000)

Compare median AIC differences with percentile-bootstrap intervals.

Parameters

Name Type Description Default
results Sequence[ModelComparison] Named participant fits following pairwise_aic_differences. required
confidence float Confidence level strictly between zero and one; default is 0.95. 0.95
n_bootstrap int Positive number of participant resamples per pair; default is 10,000. 10000

Returns

Name Type Description
medians pd.DataFrame Median row-minus-column AIC differences; negative favors the row model.
lower pd.DataFrame Lower percentile-bootstrap interval endpoints.
upper pd.DataFrame Upper interval endpoints. All three tables have NaN diagonals and NaNs for comparisons with fewer than two participants.

Notes

Aligned participants are sampled with replacement using seed 42. Each unordered pair is resampled once. Reverse entries negate the median and swap and negate the interval endpoints. The interval need not be centered on the median.

random_effects_model_selection

jaxcmr.summarize.random_effects_model_selection(log_evidence, model_names, *, alpha0=1.0, max_iter=1000, tol=1e-08, n_samples=100000)

Infer population model frequencies from participant log evidence.

Parameters

Name Type Description Default
log_evidence Float[Array | np.ndarray, 'participants models'] Nonempty finite matrix with the same participants in each model column and comparable observations. Higher values favor a model. The caller supplies integrated evidence or explicitly chooses an approximation. required
model_names Sequence[str] Names labelling the model columns in their supplied order. required
alpha0 float Positive symmetric Dirichlet prior concentration per model; default is 1. 1.0
max_iter int Positive variational-iteration limit; default is 1,000. 1000
tol float Positive tolerance on maximum absolute concentration change; default is 1e-8. 1e-08
n_samples int Positive number of Dirichlet draws for exceedance probabilities; default is 100,000, using seed 0. 100000

Returns

Name Type Description
pd.DataFrame Model, Expected Frequency, Exceedance Probability, Protected XP and Alpha columns, in supplied model order.

Raises

Name Type Description
RuntimeError If the maximum absolute concentration change does not fall below tol within max_iter iterations.

Notes

Inputs remain unchanged. This operation adds no information-criterion penalty. Pooled fits are not participant samples.

References

.. [1] Stephan et al. (2009), NeuroImage 46:1004-1017. .. [2] Rigoux et al. (2014), NeuroImage 84:971-985, equations A.17/A.20 and protected exceedance probabilities.

Reference decomposition: https://github.com/spm/spm/blob/main/spm_BMS_bor.m

bayesian_model_selection

jaxcmr.summarize.bayesian_model_selection(results, alpha0=1.0, max_iter=1000, tol=1e-08, n_samples=100000, n_obs=None)

Infer model frequencies using the AIC/AICc evidence approximation.

Parameters

Name Type Description Default
results Sequence[ModelComparison] Named participant likelihood fits following pairwise_aic_differences. Scores must be finite and participant sets must match. Pooled fits are excluded. required
alpha0 float Positive symmetric Dirichlet prior concentration per model; default is 1. 1.0
max_iter int Positive variational-iteration limit; default is 1,000. 1000
tol float Positive tolerance on maximum absolute concentration change; default is 1e-8. 1e-08
n_samples int Positive number of draws for exceedance probabilities; default is 100,000, using seed 0. 100000
n_obs array_like or None Observation counts in the first record’s original participant order. None uses AIC; supplied counts use AICc and must exceed each parameter count plus one. None

Returns

Name Type Description
pd.DataFrame Model, Expected Frequency, Exceedance Probability, Protected XP and Alpha columns, in supplied model order.

Raises

Name Type Description
ValueError If an AICc observation count is less than or equal to its parameter count plus one.
RuntimeError If the variational iteration does not converge within max_iter.

Notes

This interface aligns the records and approximates log evidence as -IC/2; it does not compute an integrated model likelihood. Inference is performed by random_effects_model_selection, which also accepts log evidence directly.
