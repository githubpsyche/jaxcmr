jaxcmr.repetition

Recall data use study positions to identify recalled items.

When an item appears more than once, several positions refer to the same item. For the study list [A, B, A], a recall recorded as position 3 refers to the item presented at positions 1 and 3.

This module finds those positions, converts recalls to each item’s first study position, and identifies repeated responses. Removing a repeated response replaces its code with zero; it does not shift later responses.

make_control_dataset constructs shuffled controls by pairing recall sequences from lists without repeated items (“pure” lists) with study layouts containing repeats (“mixed” lists). Pairings stay within participants, and each mixed trial appears once per shuffle. The recall codes are then interpreted using the paired mixed-list layout.

Finding study occurrences

item_to_study_positions Find the study positions occupied by an item.
equivalent_study_positions Find all study positions of the item at a recalled position.

Identifying and handling repeated recalls

has_repeats_per_row Identify rows containing repeated positive codes.
recalls_to_first_study_positions Represent each recalled item by its first study position.
filter_repeated_recalls Zero repeated recall codes while preserving response slots.

Constructing shuffled controls

make_control_dataset Pair shuffled pure-list recalls with mixed-list presentations by participant.

API entries

item_to_study_positions

jaxcmr.repetition.item_to_study_positions(item, presentation, size)

Find the study positions occupied by an item.

Parameters

Name Type Description Default
item Int_ Item code to find; zero represents no item. required
presentation Integer[Array, ' list_length'] Item codes in study order. Equal codes identify the same item. required
size int Output capacity. Keep the first size occurrences and pad unused entries with zero. This argument must be static under JIT. required

Returns

Name Type Description
Integer[Array, ' size'] One-based study positions, in increasing order. A missing item or item zero produces all zeros.

Examples

>>> item_to_study_positions(10, jnp.array([10, 20, 10, 30]), 3).tolist()
[1, 3, 0]

equivalent_study_positions

jaxcmr.repetition.equivalent_study_positions(study_position, presentation, size)

Find all study positions of the item at a recalled position.

Parameters

Name Type Description Default
study_position Int_ One-based position within the study list. Nonpositive values represent no recall and produce zeros. required
presentation Integer[Array, ' list_length'] Item codes in study order. Equal codes identify the same item. required
size int Output capacity, with truncation and zero padding as in item_to_study_positions. Must be static under JIT. required

Returns

Name Type Description
Integer[Array, ' size'] One-based positions of the recalled item, including the supplied position if it lies within the retained occurrences.

Examples

>>> equivalent_study_positions(3, jnp.array([10, 20, 10, 30]), 3).tolist()
[1, 3, 0]

has_repeats_per_row

jaxcmr.repetition.has_repeats_per_row(arr)

Identify rows containing repeated positive codes.

Parameters

Name Type Description Default
arr Integer[Array, ' trials recall_events'] Codes to examine independently in each row. These may represent study items or recalled positions. Zero and negative codes are ignored. required

Returns

Name Type Description
Bool[Array, ' trials'] True where a positive code occurs more than once. Different codes referring to the same item are not combined by this operation.

recalls_to_first_study_positions

jaxcmr.repetition.recalls_to_first_study_positions(rec_row, pres_row)

Represent each recalled item by its first study position.

Parameters

Name Type Description Default
rec_row Integer[Array, ' recall_events'] One-based recalled positions within this trial’s study list, with zero for no recall. Positive codes must refer to presented items. required
pres_row Integer[Array, ' study_events'] Study item codes; equal codes identify repeated presentations. required

Returns

Name Type Description
Integer[Array, ' recall_events'] Recalls mapped to each item’s first study position, preserving zeros and response slots. Repeated recalls remain; use filter_repeated_recalls separately to zero later occurrences.

Examples

>>> recalls_to_first_study_positions(
...     jnp.array([3, 2, 1, 0]), jnp.array([10, 20, 10, 30])
... ).tolist()
[1, 2, 1, 0]

filter_repeated_recalls

jaxcmr.repetition.filter_repeated_recalls(recalls)

Zero repeated recall codes while preserving response slots.

Parameters

Name Type Description Default
recalls Integer[Array, ' trials recall_events'] Recall codes, with zero for no recall. Equality of codes determines repetition. If different study positions refer to the same item, relabel with recalls_to_first_study_positions first. required

Returns

Name Type Description
Integer[Array, ' trials recall_events'] A new array retaining the first occurrence of each nonzero code and replacing later occurrences with zero. Rows are not compacted; how zero slots affect a measure is determined by that analysis.

Examples

>>> filter_repeated_recalls(jnp.array([[1, 2, 1, 3]])).tolist()
[[1, 2, 0, 3]]

make_control_dataset

jaxcmr.repetition.make_control_dataset(data, mixed_query, control_query, n_shuffles, remove_repeats=True, seed=0, recall_dependent_fields=())

Pair shuffled pure-list recalls with mixed-list presentations by participant.

Parameters

Name Type Description Default
data RecallDataset Trial data containing both conditions. Recall codes are one-based study positions; pure and mixed trials must use compatible position codes. Study metadata is taken from mixed trials, not from the pure trials supplying the recalls. The input is unchanged. required
mixed_query str Query selecting lists with repeated study items, evaluated by generate_trial_mask. required
control_query str Query selecting pure lists without repeated study items. required
n_shuffles int Positive number of shuffles per participant. Each shuffle pairs every mixed trial once with a pure recall row. Pure rows are drawn in random permutation order; use additional independent permutations when there are fewer pure trials, truncating only the last permutation. required
remove_repeats bool Whether to zero repeated recalls after relabeling each item to its first mixed-list study position. Default is True. True
seed int Random seed for reproducible pairings. Default is zero. 0
recall_dependent_fields Collection[str] Additional response fields to discard when replacing recalls. Known response fields, including rec_itemids, irt, cue_clips and _should_tabulate, are also removed. ()

Returns

Name Type Description
RecallDataset Controls grouped by participant, then shuffle, then mixed-trial order. Each included participant contributes n_shuffles * mixed_trials rows. Participants without both conditions are skipped. Study fields remain aligned; list lengths are inferred from nonzero presentations when absent from legacy input data.

Raises

Name Type Description
ValueError If no participant has both mixed and pure trials.

Notes

The control preserves pure-list recall sequences but interprets their position codes under mixed-list presentations. Positions occupied by the same mixed-list item become a single code. This is an explicit control construction; it does not estimate a repetition effect or perform a test. Shuffles are repeated pairings within participants, not new participants.
