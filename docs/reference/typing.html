Data formats and callable interfaces for recall models, simulation and fitting.

RecallDataset describes the arrays recorded on each trial, and Parameters maps parameter names to scalar model values. Array annotations specify the dtype and dimensions a caller supplies.

Memory, Context, TerminationPolicy and ResponsePolicy describe components used to build a model. MemorySearch describes how a model experiences study items and produces recall responses. A MemorySearchModelFactory constructs that model for a particular trial. A TrialSimulator uses it to carry out a study and recall procedure.

For fitting, a LossFactory constructs an objective for a dataset. LossFn scores candidate parameter sets, and a FittingAlgorithm returns estimates and objective values in a FitResult. These protocols specify the operations an implementation must supply. A model, loss or fitter can satisfy its protocol without inheriting from it.

RecallDataset

jaxcmr.typing.RecallDataset: TypedDict

Trial-indexed arrays for free or serial recall experiments.

The required fields are subject, listLength, pres_itemnos, and recalls. Their annotated shapes and integer dtypes appear below; zeros pad item and recall sequences.

pres_itemids identifies items across lists and is required by semantic models and analyses, but not by every recall dataset. Other named fields are optional. Additional fields may contain arrays of any dtype or shape, such as valence or LPP measurements. Callers must supply the optional or additional fields required by their chosen operation. Every field must have a leading trial dimension; non-trial metadata belongs outside this dict.

Fields

Name Type Description
subject Integer[Array, 'n_trials 1'] Subject ID for each trial (shape: [n_trials, 1]).
listLength Integer[Array, 'n_trials 1'] Number of valid study events per trial, including repeated presentations (shape: [n_trials, 1]).
pres_itemnos Integer[Array, 'n_trials num_presented'] Per-trial within-list item codes (shape: [n_trials, num_presented]). Positive item codes repeat when an item is presented again; 0 pads unused study slots. These codes are distinct from study positions and global IDs.
recalls Integer[Array, 'n_trials num_recalled'] Study-position codes for recalled items (shape: [n_trials, num_recalled]). A positive code p identifies the item at pres_itemnos[trial, p - 1]; 0 marks an unused response slot. Model adapters translate positions to within-list item codes, and dataset simulation returns first-occurrence study positions when an item was presented repeatedly.
pres_itemids NotRequired[Integer[Array, 'n_trials num_presented']] Per-trial cross-list item IDs (shape: [n_trials, num_presented]). These IDs reference a global word pool and may repeat across trials.
rec_itemids NotRequired[Integer[Array, 'n_trials num_recalled']] Cross-list item IDs for recalled items (shape: [n_trials, num_recalled]).
irt NotRequired[Integer[Array, 'n_trials num_recalled']] Item response times for recalled items (shape: [n_trials, num_recalled]).
session NotRequired[Integer[Array, 'n_trials 1']] Session IDs for each trial (shape: [n_trials, 1]).
listtype NotRequired[Integer[Array, 'n_trials 1']] List type for each trial (shape: [n_trials, 1]).
list_type NotRequired[Integer[Array, 'n_trials 1']] List type for each trial (shape: [n_trials, 1]).

MemorySearch

jaxcmr.typing.MemorySearch: Protocol

Study and retrieval operations used by simulation and likelihood evaluation.

Item choices are one-indexed within-list codes. Zero is ignored during study and denotes stopping during retrieval. Update methods return the new model state; callers retain the original state until they replace it. Implementations used by the numerical routines must support JAX tracing and carry their changing state in a JAX pytree.

Internal representations of studied items, context and retrieval support belong to the concrete model. Response policies and diagnostic views specify any additional information they require separately.

TrialSimulator

jaxcmr.typing.TrialSimulator: Protocol

Run a study and retrieval procedure for one trial.

The procedure determines how observed recalls constrain simulation: it may ignore them, impose the first recall, or use their count or occupied slots. Dataset simulation translates recorded study positions into within-list item codes before calling this interface, and translates generated item codes back to study positions afterward.

LossFn

jaxcmr.typing.LossFn: Protocol

Score candidate parameter vectors on selected observations.

Fitters initialize a loss with the model factory, dataset and features. Each call supplies selected trial rows, base parameters and a matrix of candidate values for the free parameters. Lower objective values are better; the chosen loss defines the measure, such as negative log likelihood or behavioral mean squared error.

FitResult

jaxcmr.typing.FitResult: TypedDict

Serialized parameter estimates and optimizer results, aligned by fit row.

fitness, nit, converged and every column in fits refer to the same rows. One fit to pooled observations produces one row; participant-wise fitting produces one row per participant. Optimizer diagnostics are optional. The objective’s meaning comes from the selected loss.

Fields

Name Type Description
fixed dict[str, float | int | bool] Base parameter values preserving numeric and Boolean scalar types. Free-parameter defaults may appear here too; fitted values in fits override them.
free dict[str, list[float]] Free-parameter names mapped to [lower_bound, upper_bound].
fitness list[float] Objective values, one per fit row. Their meaning is determined by the selected loss; likelihood examples store negative log likelihood.
nit list[int] Number of optimizer iterations or generations run for each selected fit.
converged list[bool] Whether each fit met the optimizer convergence criterion.
fits dict[str, list[float | int | bool]] Parameter columns aligned by fit row, including integer and Boolean values. The reserved subject column contains integer IDs, never floats or booleans. Participant rows have distinct IDs; a pooled fit has one row with ID -1.
hyperparameters dict[str, Any] Dictionary of hyperparameter names and their values used during fitting.
fit_time float Total time (in seconds) taken to perform the fitting.
diagnostics NotRequired[list[dict[str, Any]]] Optional diagnostics aligned with fit rows. Each entry includes subject, selected_restart and restart records, plus solver-specific details.
