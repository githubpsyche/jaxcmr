Draw behavioral summaries and arrange comparisons across datasets and conditions.

If you have a recall dataset, start with the plotter for the measure you want, such as jaxcmr.analyses.spc.plot_spc. It selects trials, calculates a serial position curve for each participant, and passes those curves to plot_mean_curve. If you already have participant scores, you can call plot_mean_curve directly. Each row is an observation and each column a position or bin. The mean and optional bootstrap interval therefore give each participant with a finite score equal weight in that column.

When writing an analysis plotter, use prepare_plot_inputs to obtain axes, trial selections and colors. Several mean curves can share those axes. format_analysis_axes labels them after the curves are drawn. For a matrix of values, matrix_heatmap displays the cells on a common color scale.

comparison_panels arranges datasets and trial selections before an analysis runs. iter_condition_curves works with participant scores that have already been calculated, separating them into curves for individual conditions. To run several configured analyses, iter_analysis_figures calls their plotters and yields each figure for display or saving.

Preparing a plot

init_plot Return the supplied axes, or create axes in a new figure.
prepare_plot_inputs Prepare collections and plotting defaults for an analysis plotter.

Drawing summaries

plot_mean_curve Draw the mean across observation rows, optionally with bootstrap intervals.
plot_mean_intervals Draw one point and its precomputed confidence interval for each group.
bootstrap_mean_errors Return finite-observation bootstrap error distances around a mean curve.
format_analysis_axes Apply labels, an optional legend and the shared analysis-plot style.
add_analysis_legend Place the legend to the right of the axes, clear of curves and error bars.

Drawing matrices

matrix_heatmap Draw a vector or matrix as a value-annotated heatmap.

Arranging comparisons

comparison_panels Arrange selected datasets for condition or dataset comparisons.
iter_condition_curves Arrange participant results into curves with matching labels and colors.

Producing and saving figures

iter_analysis_figures Create configured behavioral figures in order, one figure at a time.
save_figure Lay out and save a supplied figure without displaying or closing it.

plot_mean_curve

jaxcmr.plotting.plot_mean_curve(axis, x_values, y_values, label, color, *, draw_ci=True, confidence_level=0.95, n_resamples=9999, bootstrap_seed=None)

Draw the mean across observation rows, optionally with bootstrap intervals.

Parameters

Name Type Description Default
axis Axes Existing axes to draw on; this operation does not create a figure. required
x_values array of shape (bins,) Positions of the plotted bins. Integer-valued positions use integer ticks. required
y_values array of shape (bins,) or (observations, bins) Values by bin, optionally with multiple independent observation rows. Each finite row contributes equally within a bin. Analysis plotters normally pass participant scores; this function does not group trials. A vector is treated as one observation and receives no error bars. required
label str Legend label for the curve, including curves interrupted by missing bins. required
color str Color of the line, markers and error bars. required
draw_ci bool Draw bootstrap intervals when there is more than one observation row. True
confidence_level float Coverage passed to bootstrap_mean_errors. 0.95
n_resamples int Number of BCa bootstrap resamples for participant means, default 9999. 9999
bootstrap_seed int Seed for reproducible intervals. Fewer than two finite participant scores gives no interval; a constant sample gives a point interval. None

Returns

Name Type Description
Axes The supplied axes with the curve added. Bins with a NaN mean break the line; Matplotlib omits their markers and error bars.

matrix_heatmap

jaxcmr.plotting.matrix_heatmap(matrix, figsize=(15, 15), axis=None, label_font_size=32, annot_font_size=14, print_threshold=0.005, title='', xlabel='Column Index', ylabel='Row Index', *, colorbar=True, norm=None, row_labels=None, column_labels=None)

Draw a vector or matrix as a value-annotated heatmap.

Parameters

Name Type Description Default
matrix array of shape (values,) or (rows, columns) Values to display. A vector is drawn as one row; rows run from top to bottom. Nonfinite cells are blank. The input is not modified. required
figsize tuple of float Width and height in inches when creating a figure. Ignored with axis. (15, 15)
axis Axes Existing axes to draw on. Omit to create a figure. None
label_font_size float Font size for the title and axis labels. 32
annot_font_size float Font size for numbers drawn inside cells. 14
print_threshold float Annotate finite values whose absolute magnitude is at least this value. Annotations use two decimal places; this threshold does not affect color. 0.005
title str Title of the heatmap. ''
xlabel str Horizontal axis label. Supply the scientific meaning of the columns. 'Column Index'
ylabel str Vertical axis label. Supply the scientific meaning of the rows. 'Row Index'
colorbar bool Add a colorbar to the figure. True
norm matplotlib.colors.Normalize Mapping from values to colors. Supply a common normalization with fixed limits to compare several matrices on the same scale. By default each heatmap scales to its own finite values. The palette is magma. None
row_labels sequence of str One label per displayed row or column. Defaults to zero-based indices. Ticks are thinned to fit the available space; supplied labels stay attached to their corresponding cells. None
column_labels sequence of str One label per displayed row or column. Defaults to zero-based indices. Ticks are thinned to fit the available space; supplied labels stay attached to their corresponding cells. None

Returns

Name Type Description
tuple of Figure or SubFigure and Axes The containing figure or subfigure and heatmap axes. Drawing does not show, save or close them.

Examples

Set fixed color limits that can be reused for other heatmaps:

>>> from matplotlib.colors import Normalize
>>> scale = Normalize(vmin=0, vmax=1)
>>> figure, axis = matrix_heatmap(np.array([[0.2, 0.8]]), norm=scale)

comparison_panels

jaxcmr.plotting.comparison_panels(datasets, masks_by_dataset, dataset_labels, condition_labels, *, mode, selection_label='Selected lists')

Arrange selected datasets for condition or dataset comparisons.

Parameters

Name Type Description Default
datasets sequence of RecallDataset Nonempty ordered datasets. Their arrays are shared with the returned panels, without copying or modification. required
masks_by_dataset sequence of sequences of Boolean arrays or None One ordered condition-mask sequence per dataset. Each mask selects trials within that dataset; None selects all trials. required
dataset_labels sequence of str One label per dataset, in the same order. required
condition_labels sequence of str Labels for the common ordered conditions. required
mode Literal['conditions', 'datasets'] “conditions” requires one dataset and compares its conditions in one panel. “datasets” creates a panel for each condition, comparing all datasets within it, even when there is only one dataset. required
selection_label str Title of the single panel in conditions mode. 'Selected lists'

Returns

Name Type Description
list of dict Input arrangements containing datasets, trial_masks, labels and title. Callers may add analysis-specific options such as output position or category. Queries and figures are handled by the caller.

Notes

Each returned panel contains these fields:

Field Contents
datasets Ordered datasets to compare in this panel.
trial_masks One Boolean trial selection for each dataset entry.
labels One curve label for each dataset entry.
title The condition label, or selection_label in conditions mode.

In conditions mode, the same dataset appears once per condition with a different mask. In datasets mode, each panel contains all datasets with the corresponding condition masks. Mismatched numbers of datasets, labels, or condition masks raise ValueError.

iter_condition_curves

jaxcmr.plotting.iter_condition_curves(subject_values, condition_count, dataset_index, labels, color_cycle)

Arrange participant results into curves with matching labels and colors.

Parameters

Name Type Description Default
subject_values sequence of arrays One array per participant: bins for an unconditioned analysis, or conditions by bins for a conditioned analysis. required
condition_count int Number of conditions. Zero denotes one unconditioned curve. required
dataset_index int Position of this dataset in the caller’s comparison. required
labels sequence of str Labels selected according to condition_count and the label count. The selection rules are listed in Notes below. required
color_cycle sequence of str Nonempty colors, cycled in dataset/condition order. required

Yields

Name Type Description
tuple Participant-by-bin values, label and color for each condition in order, or one tuple for an unconditioned analysis. No averaging or drawing occurs.

Notes

The label rules are applied in this order:

Condition count Label count Labels describe
Zero Any Datasets, indexed by dataset_index.
Positive Greater than condition_count Dataset/condition pairs, with conditions varying fastest.
Greater than one At most condition_count Shared conditions, indexed by condition.
One At most condition_count Datasets, indexed by dataset_index.

Supply enough labels for the selected rule and nonempty colors. Colors cycle in dataset order for unconditioned curves, or dataset/condition order for conditioned curves. Participant order is preserved within every curve.

iter_analysis_figures

jaxcmr.plotting.iter_analysis_figures(datasets, analysis_configs, labels=None, *, base_masks=None, trial_query=None, confidence_level=0.95, figure_size=(10, 4.8), suffix='', n_resamples=9999, bootstrap_seed=None)

Create configured behavioral figures in order, one figure at a time.

Parameters

Name Type Description Default
datasets sequence of RecallDataset Already-loaded observations or simulations. required
analysis_configs sequence of mappings Each requires target: an analysis plotter callable or dotted import name. Optional entries are trial_query, figsize, labels, contrast_name, kwargs, color_cycle, title, ylim and figure_suffix. Plotters accept dataset/mask sequences and the usual analysis plot options, including axis. required
labels sequence of str Default labels, one per dataset. Configurations may override them. None
base_masks sequence of Boolean arrays or None Restrictions for each dataset. None selects all trials. Each analysis’s query is intersected with these masks. None
trial_query str Default query, overridden by a configuration’s trial_query. None
confidence_level float Default interval coverage; configuration kwargs may override it. 0.95
figure_size tuple of float Default figure width and height in inches; figsize overrides it. (10, 4.8)
suffix str Appended to the configured or target-derived figure suffix. ''

Yields

Name Type Description
tuple of Figure and str Figure and filename suffix in configuration order. Only the next requested figure is created. The caller saves, displays and closes it. Repeated targets without figure_suffix receive an additional suffix containing their one-based configuration position.

Notes

kwargs override plot options except axis: this iterator always supplies axes belonging to the figure it yields. An explicit color_cycle overrides kwargs. Titles and limits are applied to the created axes after the plotter returns. Inputs are not modified. Import targets and queries are trusted executable code, not a restricted language.

Configuration entries describe one figure:

Key Meaning and default
target Required plotter callable or dotted import name.
trial_query Query intersected with each base mask; defaults to the argument trial_query. An explicit None selects all trials within each base mask.
figsize Figure width and height in inches; defaults to figure_size.
labels Dataset labels; defaults to the labels argument, or empty labels when that argument is omitted.
contrast_name Legend title; defaults to Responses.
kwargs Additional plotter options, overriding labels, contrast_name and confidence_level when supplied.
color_cycle A non-None value overrides the corresponding entry in kwargs.
title Axes title; defaults to the plotter’s name.
ylim Vertical limits, applied after plotting when non-None.
figure_suffix Filename stem; defaults to the plotter name without a leading plot_. The suffix argument is appended.

The axis option always belongs to the new figure, including when kwargs contains axis. Repeated targets with no explicit figure_suffix append their one-based configuration position after suffix. Explicit figure_suffix values are used as supplied; the caller is responsible for distinct output names.

Other Parameters

Name Type Description Default
n_resamples int Number of BCa bootstrap resamples for participant means, default 9999. 9999
bootstrap_seed int Seed for reproducible intervals. Fewer than two finite participant scores gives no interval; a constant sample gives a point interval. None

Parameters
