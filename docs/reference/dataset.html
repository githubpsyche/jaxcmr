jaxcmr.dataset

Construct and transform recall datasets while keeping trial fields aligned.

make_dataset builds a dataset from recall sequences and study information. select_trials selects, reorders or repeats whole trial rows, carrying participant IDs, study lists and custom fields along with the responses. replace_recalls supplies new responses and removes metadata tied to the old recall events.

A recorded response identifies a one-based study position. Models use the identity of the item presented there. For the study list A, B, A, a response at position 3 becomes A under recall_positions_to_items. Converting A back with recall_items_to_positions gives position 1, its first occurrence.

Use select_conditions to inspect which trials and participants meet a selection, and select_trials to take those rows. apply_by_subject groups selected trials by participant and calls an analysis on each group. Condition inspection and participant grouping run on the host. Array-based selection and recall replacement support JAX transformations with fixed output shapes.

API entries

make_dataset

jaxcmr.dataset.make_dataset(recalls, pres_itemnos=None, listLength=None, subject=1, *, reps=1)

Construct the four core trial arrays, broadcasting singleton inputs.

Parameters

Name Type Description Default
recalls array - like One- or two-dimensional study-position recall codes. A vector denotes one trial; zero marks an unused response slot. required
pres_itemnos array - like or None One- or two-dimensional within-list item codes. A vector denotes one trial. Omit to generate sequential codes padded to the maximum length. None
listLength array - like or None Scalar, vector or single-column array of study lengths. With supplied presentations, defaults to their storage width. Supply explicit lengths for padded lists. Without presentations or lengths, the default is max(response width, highest recall code); this cannot establish an experiment’s actual study length. None
subject integer or array - like Integer participant IDs as a scalar, vector or single column. Defaults to 1. Floating-point and Boolean IDs are outside this interface. 1
reps int Positive number of copies of the complete trial sequence. Two trials A and B with reps=2 produce A, B, A, B. Simulation’s replicate_trials instead places copies of each trial together. 1

Returns

Name Type Description
RecallDataset New int32 arrays for recalls, pres_itemnos, listLength and subject. Singleton rows broadcast to the common trial count before repetition. Input arrays are unchanged.

Notes

Inputs must be integer-valued and representable as int32, with compatible trial counts. Lengths must be nonnegative and agree with presentation padding. These are caller responsibilities, not runtime value checks.

With explicit presentations, construction supports JIT and vmap; reps must be static. Generating presentations also works with a static integer listLength. Inferring their width from array values requires concrete data and must happen before JIT.

select_trials

jaxcmr.dataset.select_trials(data, trial_indices)

Select, reorder or repeat complete trial rows without changing their fields.

Parameters

Name Type Description Default
data RecallDataset Dataset whose fields share a leading trial dimension, including any custom trial, study-event and recall-event arrays. required
trial_indices Integer[Array, selected_trials] Zero-based row indices in the desired output order. Repeated indices repeat whole trials. To use a Boolean mask, first obtain its indices with jnp.flatnonzero(mask) outside JIT. required

Returns

Name Type Description
RecallDataset New dataset with the same fields and selected rows. An empty index array produces zero trial rows, retaining the remaining dimensions. The input dataset is unchanged.

Notes

This operation supports JAX transformations when the index-array shape is fixed. Vocabulary-wide features and other non-trial metadata belong outside the dataset and are not selected here.

replace_recalls

jaxcmr.dataset.replace_recalls(data, recalls, additional_recall_fields=())

Replace responses and discard metadata belonging to the old recall events.

Parameters

Name Type Description Default
data RecallDataset Dataset supplying trial and study information for the new responses. required
recalls Integer[Array, 'n_trials num_recalled'] New study-position recall codes, with one row per original trial. Response width may differ from the old recalls. Item-code responses must be translated to study positions before calling this operation. required
additional_recall_fields collection of str Custom fields tied to the previous responses, to remove as well. These must not include required dataset fields or study metadata. ()

Returns

Name Type Description
RecallDataset New mapping with the supplied recalls. The known recall-event fields rec_itemids, irt, cue_clips and _should_tabulate are removed when present, along with additional_recall_fields. Other fields are retained unchanged. No metadata is recalculated and the original mapping is unchanged.

generate_trial_mask

jaxcmr.dataset.generate_trial_mask(data, trial_query)

Evaluate a query selecting whole trials.

Parameters

Name Type Description Default
data RecallDataset Trial data available to the query as data. required
trial_query str or None Trusted Python expression producing one Boolean per trial. The names data, np and jnp are available. None selects every trial. required

Returns

Name Type Description
Bool[Array, trial_count] One-dimensional JAX mask. Column-shaped query results are flattened. The dataset is unchanged.

Examples

>>> mask = generate_trial_mask(data, "data['subject'] == 3")

generate_recall_mask

jaxcmr.dataset.generate_recall_mask(data, recall_query)

Evaluate a query selecting individual recall events.

Parameters

Name Type Description Default
data RecallDataset Trial data available to the query as data. required
recall_query str or None Trusted Python expression producing a Boolean array aligned to recalls. The names data, np and jnp are available. None selects every slot, including padding; likelihood-specific stopping rules belong to the loss. required

Returns

Name Type Description
Bool[Array, 'trial_count recall_events'] JAX mask with the same shape as recalls. The dataset is unchanged.

select_conditions

jaxcmr.dataset.select_conditions(data, selections, *, complete_lists_only=False, require_nonempty=True)

Build condition masks and report their trial and participant coverage.

Parameters

Name Type Description Default
data RecallDataset Trial-indexed recall data, including subject identities. required
selections sequence of str, Boolean vectors or None Ordered conditions. Strings use generate_trial_mask; Boolean vectors have one entry per trial; None selects every trial. Supply an outer sequence even for a single condition: [query] or [mask]. required
complete_lists_only bool Intersect each condition with rows whose pres_itemnos are positive in every stored position. This excludes any padded row, including a fully observed shorter list stored alongside longer lists. False
require_nonempty bool Reject conditions with no eligible trials. False permits a zero count and empty participant IDs. True

Returns

Name Type Description
list of TrialSelection One record per condition, preserving input order. No dataset fields are modified or sliced. This inspection runs outside JIT.

Raises

Name Type Description
ValueError A condition is empty and require_nonempty is true.

Examples

>>> selection = select_conditions(data, [data["condition"].ravel() == 1])[0]
>>> selected_data = select_trials(data, jnp.flatnonzero(selection.mask))

TrialSelection

jaxcmr.dataset.TrialSelection: NamedTuple

A condition’s mask and participant coverage, computed on the host.

Attributes

Name Type Description
mask Bool[Array, trials] One-dimensional JAX mask aligned to the original dataset.
trial_count int Number of selected trial rows.
subject_ids Integer[np.ndarray, subjects] Sorted unique IDs of selected participants.
participant_count int Read-only property giving the number of selected participants.

Notes

The record does not contain or copy selected data. Pass its mask to an analysis, or use its nonzero indices with select_trials.

jaxcmr.dataset.make_subject_trial_masks(trial_mask, subject_vector)

Partition selected trials into nonempty participant groups.

Parameters

Name Type Description Default
trial_mask Bool[Array | np.ndarray, trials] Selection aligned to the original trial rows. required
subject_vector Integer[Array | np.ndarray, trials] Participant ID for each trial, as a one-dimensional vector. required

Returns

Name Type Description
tuple of list of JAX masks and NumPy participant IDs One mask per selected participant, ordered by increasing ID. Each mask still indexes the original dataset and includes only selected trials. An empty selection returns an empty mask list and ID array.

apply_by_subject

jaxcmr.dataset.apply_by_subject(data, trial_mask, func, *args, **kwargs)

Apply an operation to the selected trial rows of each participant.

Parameters

Name Type Description Default
data RecallDataset Dataset with aligned trial fields, including any custom arrays. required
trial_mask Bool[Array, trial_count] Trials to include before grouping by participant. required
func callable Operation called as func(subject_data, *args, **kwargs). Each subject_data contains only that participant’s selected trial rows. required
*args Parameters.args Additional positional arguments passed to func. ()
**kwargs Parameters.kwargs Additional keyword arguments passed to func. {}

Returns

Name Type Description
list of Result One result per selected participant, ordered by increasing ID. No empty groups are passed to func; an empty selection returns [].

Notes

Grouping runs on the host. The supplied operation may itself be JIT-compiled; its selected dataset shapes can differ between participants. This function does not aggregate results or change the input dataset.

limit_to_first_subjects

jaxcmr.dataset.limit_to_first_subjects(data, max_subjects)

Retain trials from the lowest participant IDs without reordering rows.

Parameters

Name Type Description Default
data Mapping[str, Array] Trial-indexed arrays with a subject column. This mapping need not contain the other core recall fields. required
max_subjects int Nonnegative participant limit. Zero retains all participants, matching the convention in load_data. A limit above the participant count also retains everyone. required

Returns

Name Type Description
dict[str, Array] New mapping with selected rows of every field, in their original trial order. Empty input remains empty. The supplied mapping is unchanged.

recall_items_to_positions

jaxcmr.dataset.recall_items_to_positions(recalls, presentations)

Convert recalled item codes to their first matching study positions.

Parameters

Name Type Description Default
recalls Integer[Array, ' trials recall_events'] Within-list item codes; zero denotes an unused response slot. required
presentations Integer[Array, ' trials study_positions'] Within-list item codes for the same trials, with zero padding. required

Returns

Name Type Description
Integer[Array, ' trials recall_events'] One-based first study positions. Zero and unpresented items map to zero. Repeated presentations share their first position; analyses can recover all presentations from the dataset. Inputs remain unchanged.
