jaxcmr.loss.mse

Fit a model to behavioral measures calculated from observed and simulated recall.

Use MemorySearchSpcMseLoss when the target is recall probability by study position, or MemorySearchCatSpcMseLoss when the target is a separate curve for each category. To fit another measure, give MemorySearchMseLoss the analysis you use on observed recall. It applies that function to the observed dataset and to a simulated dataset with the same study lists.

Each candidate parameter set generates several recalls per trial. The model can stop early, and only response slots up to the observed response count are retained. Candidates use the same random keys. With several analyses, all predicted summaries come from the same simulated responses. make_factory lets you give a fitter that combination of analyses, their weights, and the scales used to compare their squared errors. Discrete recall sampling makes this loss suitable for derivative-free search.

Behavioral MSE

MemorySearchMseLoss Compare observed and predicted summaries with fixed weights and scales.
make_factory Bind dataset analyses and scoring settings into a fitter’s loss class.

Serial-position presets

MemorySearchSpcMseLoss Fit serial-position recall probabilities using 20 simulations per trial.
MemorySearchCatSpcMseLoss Fit stacked category SPCs, excluding undefined category-position bins.

API entries

MemorySearchMseLoss

jaxcmr.loss.mse.MemorySearchMseLoss(model_factory_cls, dataset, features, analysis_fn=None, simulation_count=20, *, analysis_fns=None, weights=None, scales=None, reduction='pooled', seed=0)

Compare observed and predicted summaries with fixed weights and scales.

Parameters

Name Type Description Default
model_factory_cls type[MemorySearchModelFactory] Factory creating each trial’s model, including its specific metadata. required
dataset RecallDataset Observations with position-coded recalls and trial-aligned metadata. required
features Array or None Vocabulary features passed to the factory. required
analysis_fn RecallAnalysisFn or None A single dataset analysis, named analysis in component scores. Supply this or a nonempty analysis_fns mapping. None
simulation_count int Simulations per trial, default 20. 20
analysis_fns Mapping[str, RecallAnalysisFn] or None Named JAX-compatible analyses accepting a RecallDataset. Their output shapes must agree for observations and predictions. Simulations become repeated trial rows, so the analysis defines pooling and weighting. None
weights Mapping[str, float] or None Nonnegative analysis weights, default one. Zero disables an analysis. None
scales Mapping[str, ArrayLike] or None Fixed positive residual divisors, broadcastable to each summary. None
reduction (pooled, per_analysis) Pooled divides by the weighted number of valid points. Per-analysis averages each analysis’s MSE, then takes their weighted mean. "pooled"
seed int Fixed simulation seed, default zero. Keys are reused across candidates. 0

Notes

Nonfinite observed bins are excluded. Nonfinite predictions at usable bins, or an enabled analysis with no usable observed bins, give infinite loss. Scales are not re-estimated when selecting participants. Configuration must contain at least one positive weight; weights and scales must be finite.

Return each analysis’s weighted contribution for candidate columns.

Contributions add to the total loss. Calling this separately repeats simulation with the same keys; it does not advance a random stream.

MemorySearchSpcMseLoss

jaxcmr.loss.mse.MemorySearchSpcMseLoss(model_factory_cls, dataset, features, *, simulation_count=20, seed=0)

Fit serial-position recall probabilities using 20 simulations per trial.

simulation_count and seed are optional keyword arguments. All counting, padding and repeated-presentation rules come from spc.

MemorySearchCatSpcMseLoss

jaxcmr.loss.mse.MemorySearchCatSpcMseLoss(model_factory_cls, dataset, features, *, category_field='condition', category_values=(1, 2), simulation_count=10, seed=0)

Fit stacked category SPCs, excluding undefined category-position bins.

Defaults are the condition field, categories (1, 2), ten simulations per trial and seed zero. Category summaries share one scoring denominator; a wholly absent category is ignored if other categories have observations.
